# Hand Slash — Single Clean Dismantle VFX

This version intentionally uses **one slash VFX only**:

- `dismantle-vfx.png` is the only slash image.
- The old multi-shape/arrow/vertical/diagonal VFX assets are removed.
- The slash is drawn from its CENTER.
- The slash does not follow the hand after spawning.
- Swipe direction controls rotation through the full 360 degrees.
- One slash is spawned per completed swipe.
- The slash quickly zaps in, stays fixed, then fades.
- Energy remains capped at 300.

Open `index.html` to test it, or deploy the repository with GitHub Pages.
